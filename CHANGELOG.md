# Changelog

All notable changes for Doe Sangue Angola will be documented here.

## 0.1.0 - Launch Candidate

### Added

- Admin Portal with national dashboard, monitoring, reports and settings.
- Hospital Portal with urgent requests, donors, PIN validation, reports and settings.
- Donor Mobile App experience with requests, donor profile, rewards, notifications and safety settings.
- Role-based onboarding for Admin, Hospital and Donor users.
- Shared mock data layer for connected demo flows.
- Shared services, agents and TypeScript types.
- Supabase schema, seed data and provider structure.
- CSV export for reports.
- Error, empty, loading and offline states.
- Accessibility helpers and keyboard navigation improvements.
- Investor demo mode, security audit and production monitoring architecture.
- Release, setup, architecture, environment and deployment documentation.

### Verified

- `npm run check:lines`
- `npm run audit`
- `npm run lint`
- `npm run test`
- `npm run typecheck`
- `npm run build`

### Notes

- Mock mode remains the default.
- Supabase activation is prepared but not enabled for production data yet.
