# Instalar no Android Chrome

Este guia ajuda dadores e equipas hospitalares a instalar o Doe Sangue Angola a partir do navegador.

## Antes de começar

1. Abra o link piloto no Chrome.
2. Entre com a sua conta de teste.
3. Confirme que consegue abrir a área de Dador ou Hospital.

## Instalar como app

1. Toque no botão **Instalar App** quando aparecer.
2. Se o botão não aparecer, abra o menu do Chrome.
3. Toque em **Adicionar ao ecrã inicial** ou **Instalar app**.
4. Confirme o nome **Doe Sangue Angola**.
5. Abra o ícone criado no ecrã inicial.
6. Confirme que a app abre diretamente em **/mobile** e sem barra do navegador.

## Teste rápido do Dador

1. Fazer login como dador.
2. Completar onboarding, se necessário.
3. Abrir **Pedidos** na navegação inferior.
4. Aceitar um pedido compatível.
5. Abrir **PIN** e confirmar que o PIN aparece.
6. Cancelar aceitação apenas se o teste pedir.
7. Abrir **Histórico** e **Notificações**.

## Teste rápido do Hospital

1. Fazer login como hospital no Chrome.
2. Criar pedido de sangue.
3. Ver dadores recebidos.
4. Abrir detalhe do dador.
5. Validar PIN.
6. Concluir doação.

## Sem internet

Se o telefone ficar offline, aparece uma página em Português com o botão **Tentar novamente**.
Quando a internet voltar, volte a abrir a app e continue o teste.

## Nota para pilotos

Use sempre Chrome atualizado. Se a instalação não aparecer, limpe permissões antigas do site e volte a abrir o link piloto.
