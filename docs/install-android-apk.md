# Instalar APK Android

Este guia é para instalar o APK piloto em telemóveis Android.

## Passos

1. Abra o link do build enviado pela equipa Doe Sangue Angola.
2. Toque em **Download** para baixar o ficheiro `.apk`.
3. Se o Android pedir, autorize a instalação a partir do navegador.
4. Toque em **Instalar**.
5. Abra **Doe Sangue Angola** no ecrã inicial.

## Se aparecer aviso de segurança

O Android pode avisar que a app veio de fora da Play Store.
Para o piloto, confirme apenas se o link veio da equipa oficial.

## Primeiro arranque

1. Aceite permissões necessárias.
2. Se for dador, entre e complete o perfil.
3. Se for hospital, entre e confirme o painel.
4. Ative notificações quando solicitado.

## Problemas comuns

- **Não instala**: confirme espaço livre no telemóvel.
- **Não abre**: desinstale versão antiga e instale novamente.
- **Sem notificações**: confirme permissão de notificações nas definições Android.
- **Sem dados**: confirme ligação à internet e conta correta.
