# Processo de Feedback do Piloto

Durante o piloto, dadores, hospitais e administradores podem reportar problemas diretamente na plataforma.

## Onde reportar

- Dador: botão **Reportar Problema** no app.
- Hospital: botão **Reportar Problema** no cabeçalho do painel.
- Admin: botão **Reportar Problema** no Centro de Operações.

## Campos enviados

- função do utilizador
- página ou ecrã
- tipo de problema
- gravidade
- descrição
- contacto opcional
- data de criação

## Tipos de problema

- Bug
- Problema de login
- Problema com pedido
- Problema com PIN
- Problema com notificação
- Confusão na interface
- Outro

## Gravidade

- Baixa: não bloqueia o teste
- Média: atrapalha, mas há alternativa
- Alta: bloqueia parte importante do fluxo
- Crítica: impede piloto, doação ou validação de PIN

## Gestão pelo Admin

No Admin Dashboard, a equipa pode:

1. Ver todos os reportes.
2. Filtrar por gravidade.
3. Filtrar por estado.
4. Marcar como:
   - Aberto
   - Em progresso
   - Resolvido

## Mensagem ao testador

Quando o envio funciona, o testador vê:

“Obrigado. A sua mensagem foi enviada.”

## Rotina recomendada

1. Rever feedback no início e fim de cada dia de piloto.
2. Resolver primeiro problemas críticos e altos.
3. Registar decisões em auditoria quando houver ação operacional.
4. Confirmar com o testador antes de marcar como resolvido.
