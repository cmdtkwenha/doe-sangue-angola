# Guia do Testador Piloto

Use este roteiro para validar o APK Android do Doe Sangue Angola.

## Checklist de instalação

- Recebi o link oficial do APK.
- Instalei o APK no Android.
- Abri a app sem Expo Go.
- Permiti notificações quando solicitado.
- Confirmei que a internet está ligada.

## Fluxo do dador

1. Fazer login com conta piloto.
2. Completar perfil, se a app pedir.
3. Confirmar tipo sanguíneo, província e município.
4. Abrir pedidos disponíveis.
5. Aceitar um pedido compatível.
6. Confirmar que o PIN aparece.
7. Abrir notificações.
8. Abrir perfil/definições.
9. Reportar qualquer erro à equipa.

## Fluxo do hospital

1. Fazer login no painel hospitalar pelo navegador ou PWA.
2. Criar pedido de sangue.
3. Confirmar que o dador aparece em `Dadores Recebidos`.
4. Validar PIN apresentado pelo dador.
5. Concluir doação.
6. Confirmar que admin vê atualização.

## Como reportar problema

Envie:

- modelo do telemóvel
- versão Android
- email da conta piloto
- passo onde falhou
- print do erro, se possível

## Resultado esperado

O dador consegue aceitar pedido, ver PIN e receber notificações.
O hospital consegue validar PIN e concluir a doação.
