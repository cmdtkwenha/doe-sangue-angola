# Instalar no iPhone Safari

No iPhone, a instalação é feita pelo Safari usando **Adicionar ao ecrã inicial**.

## Antes de começar

1. Abra o link piloto no Safari.
2. Entre com a sua conta de teste.
3. Confirme que a área de Dador ou Hospital abre corretamente.

## Instalar como app

1. Toque no ícone **Partilhar** do Safari.
2. Escolha **Adicionar ao ecrã inicial**.
3. Confirme o nome **Doe Sangue Angola**.
4. Toque em **Adicionar**.
5. Abra a app pelo novo ícone no ecrã inicial.
6. Confirme que a app abre sem barra do Safari e respeita a área segura do ecrã.

## Teste rápido do Dador

1. Fazer login como dador.
2. Completar perfil, se necessário.
3. Abrir **Pedidos** na navegação inferior.
4. Aceitar um pedido compatível.
5. Abrir **PIN** e confirmar que o PIN fica visível.
6. Cancelar aceitação apenas se o teste pedir.
7. Ver **Histórico** e notificações.

## Teste rápido do Hospital

1. Fazer login como hospital.
2. Criar pedido.
3. Ver dadores recebidos.
4. Abrir detalhe do dador.
5. Validar PIN.
6. Concluir doação.

## Nota para pilotos

O Safari pode não mostrar o mesmo botão automático do Chrome. Use sempre **Partilhar → Adicionar ao ecrã inicial**.
Se estiver offline, use **Tentar novamente** quando a ligação voltar.

## Problemas comuns

- Se abrir no Safari em vez de app instalada, remova o ícone antigo e adicione novamente.
- Se a sessão expirar, faça login outra vez; os dados reais continuam no Supabase.
