# Checklist Imprimível do Dia do Piloto

## Antes do Piloto

- [ ] Feature freeze ativo.
- [ ] Supabase operacional.
- [ ] Vercel operacional.
- [ ] APK instalado no telemóvel do dador.
- [ ] Admin consegue entrar.
- [ ] Hospital consegue entrar.
- [ ] Dador consegue entrar.
- [ ] Hospital ligado a hospital aprovado.
- [ ] Dador com perfil completo.
- [ ] `/status` operacional.
- [ ] `/admin/launch` operacional.
- [ ] CSV inicial exportado.
- [ ] Contacto de suporte confirmado.

## Durante o Piloto

- [ ] Admin abriu painel de lançamento.
- [ ] Hospital criou pedido urgente.
- [ ] Admin viu pedido.
- [ ] Dador viu pedido compatível.
- [ ] Dador aceitou pedido.
- [ ] PIN apareceu na app do dador.
- [ ] Hospital viu dador aceite.
- [ ] Hospital marcou chegada.
- [ ] Hospital validou PIN.
- [ ] Hospital concluiu doação.
- [ ] Admin viu auditoria.
- [ ] Notificações apareceram.
- [ ] Feedback do dador recolhido.
- [ ] Feedback do hospital recolhido.
- [ ] Feedback do admin recolhido.
- [ ] Problemas foram reportados com gravidade.

## Depois do Piloto

- [ ] CSV final exportado.
- [ ] Problemas críticos revistos.
- [ ] Feedback consolidado.
- [ ] Capturas de ecrã arquivadas.
- [ ] Métricas principais registadas.
- [ ] Decisão tomada: avançar, repetir ou pausar.
- [ ] Próximas correções priorizadas.
